# MARKIZ

Полная пересборка [Aldiyardev/Markizsite](https://github.com/Aldiyardev/Markizsite).

## Что взято из оригинала

- арт `Markiz.jpg`
- логотип / фавиконы
- ролик `Amirtop.mp4` (сжат с 4.0 МБ до ~1.7 МБ)
- слоган **Y A U GAE**
- Telegram `@Markizmlbb`

## Что выкинуто

- битый `http-equiv`, невалидный тег `<text>`
- Leaflet без карты
- заглушки Somethin2–4
- видео, обёрнутое в ссылку целиком
- пустой service-worker и дубли manifest

## Запуск

Откройте `index.html` или залейте папку на GitHub Pages / любой static host.

Если заменяете файлы в исходном репозитории, достаточно скопировать содержимое этой папки в корень репо.
